# Security policy

## Reporting a vulnerability

Report a vulnerability privately through GitHub private vulnerability reporting:
<https://github.com/Autonomy-Logic/autonomy-docker/security/advisories/new> (the Security tab, "Report a
vulnerability").

Do not open a public issue or pull request for a vulnerability.

## Scope

This policy covers the content of this repository and the base images it publishes to `ghcr.io/autonomy-logic`. A
vulnerability in an upstream package is reported upstream as well.
